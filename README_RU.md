# Пересчет для доработки статьи

## Состав
- `dantistUtils_corrected.py`: исходный модуль с исправленным mean_colors и необязательным импортом прикладного paths. Старые имена выходов оставлены для совместимости; их нельзя трактовать как клинические показатели.
- `qlf_reanalysis.py`: независимый описательный расчет с явными определениями показателей, без лечения и клинических степеней тяжести.
- `new_analyse2_corrected.ipynb`: выполненный ноутбук с встроенными графиками.
- `results`: базовые показатели, сравнение старого и нового расчета, чувствительность порогов и размеров компонентов, гибридные доли и входной манифест.
- `VALIDATION.txt`: выполненные проверки и выявленное расхождение округления исходного вывода.

## Запуск
Установите Python 3.12 и зависимости из requirements.txt.
Получите снимки из https://github.com/BysonHunter/dantist_images и переключитесь на commit `90ca8f1ea53dcea5715cf3feac8f9aa568ed0212`.

```bash
python qlf_reanalysis.py --images /path/to/dantist_images --output results
```

Для ноутбука задайте QLF_IMAGES_DIR или положите dantist_images рядом с ноутбуком.

## Определения
green/red area_pct: доля исходной вычислительной маски зубов после удаления компонент меньше minimum_px.
hybrid area_pct: доля eligible domain гибридной функции после того же фильтра. Знаменатели различаются.
q0–q5: доли гибридного eligible domain ДО компонентной фильтрации. q0 — превышение 45; q1–q4 — интервалы (45,60], (60,75], (75,90], (90,120]; q5 — >120.
mean_signal: среднее по сохраненным пикселям; отсутствие кандидатов дает пустое значение, а не измеренный ноль.
IoU: сравнение маски с базовыми параметрами того же метода, а не с клиническим эталоном. Две пустые маски дают IoU=1.
Для зеленого канала сохранены операции float32 и строгая граница >, как в исходном ноутбуке.

## Ограничения
В наборе 20 файлов, а не доказанные 20 независимых пациентов. Сегментация 017 не проходит фиксированный фильтр; результат исключен из числовых сводок, отказ сохранен.
Нет внешнего набора, пространственной разметки, подтвержденных режимов съемки и объектной калибровки. Клиническая точность и механизм исключения налета/артефактов не установлены.
Представленные новые код и результаты не загружались в публичный репозиторий приложения.
