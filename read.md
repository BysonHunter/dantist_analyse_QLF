# QLF Analyzer (Dental Enamel)

Веб-приложение для анализа деминерализации зубной эмали по QLF-снимкам.

## Что делает проект

- Загружает изображение и автоматически уменьшает большие файлы (с сохранением пропорций).
- Позволяет выбрать ROI (область интереса) прямо на изображении.
- Выполняет 3 типа анализа:
  - `Red CH` (красный канал),
  - `Green CH` (зелёный канал),
  - `QLF DF` (алгоритм из 3-й ячейки `new_analyse2.ipynb`, по потере флуоресценции DF).
- Показывает:
  - изображения с наложением поражений,
  - табличные метрики для ROI и для всей области зубов,
  - цветовые легенды.
- Позволяет скачать ZIP-архив с результатами (PNG + JSON + TXT-отчёт).

## Технологии

- Backend: `Flask`, `OpenCV`, `NumPy`
- Frontend: HTML/CSS/JavaScript (шаблон `templates/index.html`)
- Аналитика: `dantistUtils.py`, `colorpalette.py`

## Структура (основное)

- `app.py` — Flask API, маршруты загрузки/анализа/сохранения.
- `dantistUtils.py` — сегментация и базовые алгоритмы анализа.
- `templates/index.html` — интерфейс и отображение результатов.
- `uploads/` — загруженные изображения.
- `results/` — сохранённые ZIP-архивы результатов.
- `new_analyse2.ipynb` — исследовательский ноутбук с альтернативными алгоритмами.

## API (кратко)

- `POST /upload` — загрузка изображения.
- `POST /analyze` — запуск анализа по выбранному ROI.
- `POST /save_results` — подготовка и сохранение архива.
- `GET /download/<filename>` — скачивание архива.

## Локальный запуск

```bash
pip install -r requirements.txt
python app.py
```

По умолчанию приложение стартует на `http://localhost:5000`.

## Docker

Проект содержит:

- `Dockerfile`
- `docker-compose.yml`
- `.dockerignore`

Запуск через compose:

```bash
docker compose up --build
```

## Формат сохраняемых результатов

В архив добавляются (в зависимости от доступных анализов):

- изображения ROI и all-teeth для каждого анализа (`Red CH`, `Green CH`, `QLF DF`);
- JSON с метриками по каждому анализу;
- текстовый отчёт.

## Примечания

- Интерфейс поддерживает:
  - сворачивание блоков инструкций и результатов по каналам,
  - клик по изображению результата для увеличения в модальном окне,
  - компактный вывод легенд.
